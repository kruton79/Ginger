# Трекер тренувань

Консольна програма для відстеження прогресу в тренуваннях, аналізу планових та фактичних підходів, повторень і загального стану.

## Опис теми
Назва:        Трекер тренувань
Для кого:     для мене, щоб бачити прогрес в тренуваннях
Запис:        дата;вправа;план_підходів;факт_підходів;повтори;стан
Операції:     додати, показати всі, знайти за вправою
Звіти:        загальна кількість виконаних та запланованих підходів і повторень за кожною вправою

## Запуск
## Запуск сервера
python app.py

## Перевірка через curl (в іншому вікні терміналу)
1. Додати запис:
curl -X POST http://127.0.0.1:5000/items -H "Content-Type: application/json" -d '{"date": "2026-10-10", "exercise": "Відтискання", "target_sets": 4, "sets": 4, "reps": 20, "note": "Клас"}'

2. Отримати всі записи:
curl http://127.0.0.1:5000/items

3. Знайти за вправою:
curl "http://127.0.0.1:5000/items?exercise=Відтискання"

4. Звіт:
curl http://127.0.0.1:5000/report

5. Видалити запис за ID (наприклад, ID = 1):
curl -X DELETE http://127.0.0.1:5000/items/1

## Формат даних
data.txt, один запис на рядок:
2026-10-09;Відтискання;4;4;20;Все за планом
2026-10-09;Присідання;4;2;15;Заболіло коліно
