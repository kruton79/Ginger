Назва:         Трекер тренувань
Для кого:      для мене, щоб бачити прогрес в тренуваннях
Запис:         дата, категорія вправи,кількість повторів,кількість підходів,коментар щодо стану під час тренування 
Операції:      показати всі вправи за певну дату,знайти за типом вправи кількість підходів і повторень в різні дні,змінити за надобності
Звіти:         прогрес по кожній вправі(збільшення ваги або кількості підходів),рекорди(жим,тяга і т.д),загальний стан під час тренувань за певний період
