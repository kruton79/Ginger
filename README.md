# Трекер тренувань

Консольна програма для відстеження прогресу в тренуваннях, аналізу підходів, повторень та загального стану.

## Опис теми
Назва:        Трекер тренувань
Для кого:     для мене, щоб бачити прогрес в тренуваннях
Запис:        дата;вправа;повтори;підходи;стан
Операції:     додати, показати всі, знайти за вправою
Звіти:        загальна кількість підходів та повторень за кожною вправою

## Запуск
python cli.py add 2026-10-09 "Відтискання" 20 4 "Чудове почуття"
python cli.py list
python cli.py find "Відтискання"
python cli.py report

## Формат даних
data.txt, один запис на рядок:
2026-10-09;Відтискання;20;4;Чудове почуття
